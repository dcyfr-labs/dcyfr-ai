# Archive

Historical v1.0.0 launch-era reports (January 2026). They describe the state of the project at launch and are kept for reference only. The current package is at 3.x; see [CHANGELOG.md](../../CHANGELOG.md) and the [docs index](../README.md).

`CHANGESETS_WORKFLOW.md` and `AUTOMATED_RELEASE_SETUP.md` describe the Changesets release flow the project used before it moved to release-please. The current process is in [RELEASE_MANAGEMENT.md](../RELEASE_MANAGEMENT.md).

`OPENTUI_INTEGRATION.md` is the delivery report for the terminal UI work, including the move away from OpenTUI. The current implementation is described in [TUI_IMPLEMENTATION.md](../TUI_IMPLEMENTATION.md).
